# Continue From Project State

Read `MASTER_PLAN.md`, `TASKS.md`, `HANDOFF.md`, the project brief, and applicable contracts.

Execute as many sequential waves as the environment allows. Do not ask for routine approval. For each wave:

1. select the earliest unblocked task;
2. inspect only relevant files;
3. write or update tests;
4. implement the smallest complete change;
5. run the narrowest verification;
6. repair failures;
7. update task state and handoff evidence;
8. continue to the next wave.

Stop only for a genuine blocker, missing authorization, destructive action, or consequential product decision. Report only verified work, exact failures, and the next action.
