# Compose a Project Prompt

Build the working brief from these parts, in order:

1. `templates/PROJECT_BRIEF.md` — fill objective, scope, constraints, and acceptance criteria.
2. `templates/MASTER_PLAN.md` — define waves and dependencies.
3. `templates/TASKS.md` — create the initial task state.
4. `templates/ARCHITECTURE.md` — record settled boundaries and decisions.
5. Select one execution prompt: `implement-from-spec.md`, `continue-from-state.md`, or `tdd-wave.md`.
6. Attach only applicable contracts and checklists.
7. Add `templates/HANDOFF.md` and `templates/MANIFEST.md` for external transfer.

Do not paste every library document into every prompt. Include only documents relevant to the project and state their precedence.
