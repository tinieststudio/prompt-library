# Bootstrap From ZIP

You are receiving a project ZIP. Before editing:

1. Read `AGENTS.md`, `MASTER_PLAN.md`, `TASKS.md`, `ARCHITECTURE.md`, and `README.md`.
2. Confirm the verification command and available dependencies.
3. Identify the earliest unblocked task.
4. Inspect only the files relevant to that task.

Then execute unblocked waves autonomously. After every wave, run verification, repair failures, and update `TASKS.md`. Before ending, update `HANDOFF.md` and report exact files, commands, results, blockers, and next action.

Never include secrets in output or ZIP artifacts. Never treat a successful build as proof that browser behavior, accessibility, or integration contracts passed unless those checks were actually run.
