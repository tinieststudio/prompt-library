# Implement From Specification

You are implementing the attached specification. Treat it as the contract.

Rules:

1. Inspect the provided files and environment before editing.
2. Identify ambiguities and resolve them conservatively from the specification.
3. Write tests before implementation for each behavior wave.
4. Implement the smallest complete change.
5. Run the narrowest relevant tests after each wave.
6. Do not add placeholders, TODOs, mocks, silent fallbacks, or unrelated refactors.
7. Report exact files, commands, versions, test results, screenshots, and remaining risks.
8. Never claim a test passed unless you ran it and observed the result.

Work in waves and stop only after the current wave has evidence of passing tests.
