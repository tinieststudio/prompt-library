# Portable Design Studio

Use this project with `templates/standalone-browser-script.md`, `prompts/implement-from-spec.md`, and `contracts/evidence-report.md`.

The complete specification is maintained in the project handoff brief. The studio must be portable, dependency-free at runtime, Shadow-DOM isolated, Bearnie/Astro/Tailwind compatible, Palette-compatible through golden fixtures, deterministic, accessible, automatically contrast-correcting, and free of network, filesystem, repository, telemetry, and production-injection behavior.

The external model produces a candidate. OMP independently verifies it before integration.
