# Evidence Report Contract

Every completed external-model task must report:

- objective;
- files created or changed;
- exact commands run;
- runtime and tool versions;
- test counts and conclusions;
- browser screenshots for visual behavior;
- network and filesystem observations where relevant;
- skipped tests and reasons;
- known limitations;
- unresolved failures;
- exact next action.

Statements such as “tested successfully” are insufficient without commands and observable results.
