# Evidence and Claims

Use provider-neutral instructions so the same brief works in ChatGPT, Gemini, OMP, or another agent.

Never claim a build, test, browser interaction, screenshot, scan, or deployment passed unless it was actually executed and observed in the current environment.

Every result must include:

- exact command or interaction;
- tool and runtime versions when relevant;
- pass/fail outcome;
- test totals or key assertions;
- artifact or screenshot location for visual evidence;
- skipped checks and reasons;
- remaining assumptions and limitations.

External-model results are provisional until independently reproduced in the receiving project environment.
