# Versioning and Change Policy

Reusable documents use a calendar version in their heading when behavior changes. Project handoffs record the library revision used.

- Clarifications that preserve behavior: minor revision.
- New required fields or checks: minor revision with migration notes.
- Changed precedence, evidence, security, or release behavior: major revision.
- Fixes to wording or examples: patch revision.

When changing a contract or shared prompt, update affected examples and regression scenarios. Do not silently invalidate an existing project handoff; document the compatibility impact.
