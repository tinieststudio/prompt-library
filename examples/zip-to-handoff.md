# Worked Example: ZIP to Handoff

1. **Intake** — read `AGENTS.md`, `PROJECT_BRIEF.md`, `MASTER_PLAN.md`, `TASKS.md`, `ARCHITECTURE.md`, and `README.md`.
2. **Capability check** — record runtime, browser, filesystem, and network capabilities.
3. **Integrity check** — verify the manifest, source identity, and secret scan.
4. **Planning** — select the earliest unblocked task from `TASKS.md`.
5. **Implementation** — write a focused test, implement the smallest change, and run verification.
6. **Repair** — fix failures before advancing the wave.
7. **Review** — inspect scope, security, accessibility, portability, and evidence.
8. **Handoff** — update `TASKS.md` and `HANDOFF.md` with exact results and the next action.
9. **OMP integration** — apply the patch, independently reproduce checks, and record discrepancies.

The external agent's output is a candidate until OMP verification passes.
