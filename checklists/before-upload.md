# Before External Upload

- [ ] Read the project brief and applicable contracts.
- [ ] Run the required tests and record results.
- [ ] Scan the exact handoff files for secrets.
- [ ] Exclude credentials, `.env`, keys, caches, build output, `.git`, and unrelated archives.
- [ ] Record source commit or working-tree identity.
- [ ] Create an artifact manifest.
- [ ] Include tests, fixtures, manifests, lockfiles, and state files.
- [ ] Confirm non-goals and known failures are documented.
