# Before OMP Integration

- [ ] Verify the artifact manifest and source identity.
- [ ] Inspect the diff before applying it.
- [ ] Install from the lockfile.
- [ ] Re-run required unit, integration, browser, accessibility, security, and packaging checks.
- [ ] Inspect visual evidence.
- [ ] Check production output and network behavior where applicable.
- [ ] Run the repository preflight gate.
- [ ] Record discrepancies between external and OMP results.
