# Agent Instructions

This repository stores reusable prompts, contracts, templates, examples, and project briefs—not implementation source code.

- Read `README.md` and `contracts/instruction-precedence.md` before editing.
- Preserve the distinction between normative contracts, reusable prompts, templates, examples, and project briefs.
- Avoid duplicate documents and unnecessary process.
- Keep instructions provider-neutral unless a file is explicitly provider-specific.
- Update examples and regression scenarios when changing shared behavior.
- Do not include secrets, credentials, private client data, caches, build output, or implementation artifacts.
- Verify links and structure before committing.
