# Agent Instructions

Read this file before editing. It defines standing rules for this project.

## Operating mode

- Read `MASTER_PLAN.md`, `TASKS.md`, `ARCHITECTURE.md`, and `README.md` before implementation.
- Choose the earliest unblocked task.
- Work in independently verifiable waves.
- Do not ask for routine approval.
- Do not change architecture decisions without recording the reason.

## Quality

- Write or update tests before implementation where practical.
- Run the documented verification command after each wave.
- Never claim unobserved results.
- Do not add placeholders, fake tests, silent fallbacks, or unrelated refactors.

## State

Update `TASKS.md` after each completed or blocked task. Update `HANDOFF.md` before ending the session. Include exact commands, results, limitations, and the next action.
