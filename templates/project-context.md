# Project Context Files

## ARCHITECTURE.md

Record settled boundaries, module responsibilities, public contracts, dependency choices, data flow, security constraints, and rejected alternatives. Agents must preserve these decisions unless the task explicitly changes them.

## README.md

Record purpose, supported environments, setup, verification commands, usage, and release process. Keep commands executable and current.

## ZIP handoff

When an external model receives a ZIP, include `AGENTS.md`, `MASTER_PLAN.md`, `TASKS.md`, `ARCHITECTURE.md`, `README.md`, source, tests, fixtures, manifests, and lockfiles. Exclude secrets, credentials, caches, build output, `.git`, and unrelated archives.
